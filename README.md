## 📖 Sobre

O **Hair Day** é uma aplicação web para gerenciamento de agendamentos de uma barbearia.

O sistema permite que o usuário escolha uma data, visualize os horários disponíveis, realize novos agendamentos e cancele horários já cadastrados. Todas as informações são persistidas utilizando uma API simulada com **JSON Server**.

Este projeto foi desenvolvido durante a formação **Full-Stack da Rocketseat**, com foco em JavaScript moderno, organização de código e integração com APIs. :contentReference[oaicite:0]{index=0}

---

## ✨ Funcionalidades

- 📅 Selecionar uma data
- ⏰ Exibir horários disponíveis
- ✂️ Agendar um atendimento
- ❌ Cancelar agendamentos
- 🔄 Atualizar automaticamente a agenda
- 📡 Integração com API REST

## 🚀 Como executar

Clone o repositório

```bash
git clone https://github.com/MiguelS-Dev/hairday-template-main.git
```

Entre na pasta

```bash
cd hairday-template-main
```

Instale as dependências

```bash
npm install
```

Inicie o servidor

```bash
npm run server
```

Execute a aplicação

```bash
npm run dev
```
